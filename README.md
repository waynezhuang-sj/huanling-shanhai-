# 唤灵山海

类宝可梦的像素回合制收集 RPG。怪物取材《山海经》（公有领域），美术与设定原创。

> 你扮演的不是「训练师」，而是**唤灵者** —— 与山海神兽结契，战时召唤它们降临。

## 现在能玩什么（M1）

- 两张地图：青丘镇 / 青丘野径
- 四方向行走动画，支持斜向移动
- 树木 / 水域 / 建筑碰撞
- 走到地图边缘自动切换地图

## 技术栈

| 层 | 选型 |
|---|---|
| 引擎 | Phaser 3 |
| 语言 | TypeScript |
| 构建 | Vite |
| 部署 | GitHub Pages |

**美术全部由 `BootScene.ts` 程序生成占位像素**，零素材依赖。后续替换真素材只需改这一个文件。

## 本地运行

```bash
npm install
npm run dev      # 开发服务器 http://127.0.0.1:5173
npm run build    # 产出 dist/
npm run preview  # 预览构建结果
```
