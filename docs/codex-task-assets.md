> **本任务只产出图片素材。禁止修改任何代码。**

## 二、必须交付的文件

| 文件 | 规格 | 内容 |
|---|---|---|
| `tiles.png` | 16×16 网格，**12 列**，每帧 16×16 | 场景图块集，见下表 |
| `hero.png` | 每帧 **16×24**，4 列 × 3 行 = 12 帧 | 主角四方向行走：下/左/右/上，各 3 帧 |
| `npc.png` | 每帧 **16×24**，3 列 × 1 行 = 3 帧 | 三个 NPC 站立像：巫医（老者）、货郎（青年）、浣衣女（少女） |
| `creatures.png` | 每帧 **64×64**，2 列 × 2 行 = 4 帧 | 四只神兽战斗立绘（见下表） |
| `ui.png` | 单张，需在 manifest 里标注各部件矩形 | 对话框九宫格、按钮底、血条底/填充、摇杆底盘与摇杆头 |
| `manifest.json` | — | 每个文件的帧尺寸、总帧数、每帧语义索引（见第四节） |
| `CREDITS.md` | — | 每套素材的来源链接 + 授权类型（必须 CC0 或 CC-BY） |
| `contact_sheet.png` | 预览图 | 把所有素材按类别拼成一张，标注索引，供人眼验收 |

### tiles.png 必须包含（按此顺序排列）

| 序号 | 内容 | 变体数 |
|---|---|---|
| 0-2 | 草地 | 3（纯色 / 带草簇 / 带小花） |
| 3-5 | 土路 | 3（中间 / 左边 / 右边，能拼成带边的路） |
| 6-7 | 水面 | 2 |
| 8-10 | 树 | 3（圆冠、尖冠、秋色） |
| 11-13 | 灌木/草丛 | 3 |
| 14-15 | 花 / 蘑菇 | 2 |
| 16-17 | 石头 | 2 |
| 18-20 | 屋顶 | 3（左 / 中 / 右） |
| 21-23 | 墙体 | 3（左 / 中 / 右） |
| 24-25 | 门 | 2 |
| 26-27 | 窗 | 2 |
| 28-30 | 木栅栏 | 3（左 / 中 / 右，能连成一条） |
| 31-32 | 路牌 / 木箱 | 2 |

合计 ≥ 33 帧，不足 12 列的末行留空即可。

### creatures.png 四只神兽（按此顺序）

| 帧 | 名字 | 五行 | 形象要求 |
|---|---|---|---|
| 0 | 鹿蜀 | 木 | 马身、白首、虎纹、赤尾 |
| 1 | 赤鱬 | 水 | 鱼身、人面、赤色 |
| 2 | 讙 | 火 | 狸身、白首、独目倾向 |
| 3 | 石魅 | 土 | 山石所化、粗壮、无眼 |

**画风要求**：16 色以内、清晰描边、正侧面朝左，64×64 内留 4px 透明边距。

## 三、素材来源规则

- **只允许 CC0 或 CC-BY**（必须能商用、允许修改）
- 优先策略（按顺序尝试）：
  1. 从公开 CC0 素材包下载后**裁剪/重排**成上表规格（推荐 Kenney、OpenGameArt）
  2. 若找不到合适的（尤其是四只神兽），允许用脚本**程序化绘制**像素图（PIL / canvas），但必须保持 16 色以内、有描边、风格统一
- **禁止**：任天堂/宝可梦或任何未经授权的素材、来源不明的图
- 每套素材都要写进 `CREDITS.md`：名称、链接、授权、改动说明

## 五、必须完成的机检（不许空口说完成）

写一个 `public/assets/mvp/_verify.py`，用 PIL 实际打开每个 PNG 并断言：

1. 文件存在
2. 图像尺寸 == `cols × frameW` × `rows × frameH`
3. 每帧不是全透明（逐帧算 alpha 覆盖率，>5%）
4. 四只神兽互不相同（帧间像素差异 > 10%）
5. `hero.png` 12 帧齐全，且四个方向的首帧互不相同

运行它并把**完整输出**贴进汇报。
