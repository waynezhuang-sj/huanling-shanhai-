# Codex 任务：提升《唤灵山海》美术审美

你会在提示里看到 3 张图：

1. `ref_shanhai.png` —— **目标风格参考**：山海行《水泽》场景，工笔线条 + 石青石绿 + 朱砂设色 + 云气纹样，低饱和、有层次。
2. `current_town.png` —— **当前城镇画面**：用 Kenney 卡通图块，已做过一次调色。
3. `current_battle.png` —— **当前战斗画面**：神兽立绘已换成 imagegen 生成的工笔图 + 像素化处理。

## 权限边界（必须严格遵守）

| | |
|---|---|
| ✅ 可改 | `public/assets/**` 图片、`scripts/*.py` 美术生成/处理脚本、`docs/美术说明.md` |
| ❌ 不可改 | `src/**` 任何代码、`package.json`、`vite.config.ts`、`.github/**`、`src/data/maps.ts` |

你有内置 imagegen 可用。**不要用 PIL 手绘形状冒充插画**——PIL 只用于切图、抠底、降色、描边等后处理。

---

## 第一步：自评（必须先做，不许跳过）

对着 3 张图，列出当前画面**最丑的 5 个具体问题**。每条必须写清：

- **在哪**：哪个区域/哪个图块/哪个元素
- **为什么丑**：造型？比例？配色？细节密度？画风冲突？边缘处理？
- **参考图怎么做的**：对照 `ref_shanhai.png` 说明差异

不准写"不够精致""缺乏氛围"这类空话。要具体到"路边有一圈红褐色虚线装饰，像撒了一地碎屑"这种程度。

---

## 第二步：重做地形图集

用 imagegen 生成中式青绿山水风格的地表素材，切成 16×16 网格：

- 草地 2–3 变体、石板路（中路 + 左/右边）、水面 2 帧
- 树 3 种（松/阔叶/秋色）、山石、芦苇
- 木栅栏（左/中/右）、青瓦屋顶（左/中/右）、白墙（左/中/右）
- 木门、窗、灯笼

输出 `public/assets/mvp/tiles.png`，并在 manifest 里写清**帧号 → 名称**。

硬性要求：
- 工笔线条、石青石绿朱砂赭石、低饱和、**深色描边**
- 每块地形图块**必须能无缝平铺**（检查左右/上下边缘像素：左边界 = 右邻块右边界）
- 不要出现"装饰碎屑铺满路面"这类设计
