# 《唤灵山海》地形美术交付

执行依据：`docs/codex-task-aesthetic.md`。本次修改限于 `public/assets/**`、`scripts/*.py` 和本文；没有修改 `src/**`、依赖、构建配置或工作流。2026-10-22，使用内置 imagegen 生成原画；Pillow 只负责裁切、缩放、降色、透明处理、拼接和边界像素校正，没有用图元绘制代替插画。

## 第三步：真实自检和一轮迭代

第一版是在 `--revision 0` 执行后，实际打开 `contact_sheet_v1.png` 与 `town_v1.png` 目视检查的。发现：

1. 草地原画中的细笔触缩成 16×16 后聚成斑驳噪声；石板纹理重复太密，远看仍偏碎。
2. 水面亮色云纹平铺后形成强烈规则斜纹；原画看着柔和，连续铺设却明显重复。
3. 把完整屋顶放进现有地图的四行屋顶，每行都出现檐口，像百叶窗；白墙每行也重复檐下横带。
4. 模块边缘尚未经像素约束，不能靠原画目测宣称无缝。

本轮处理：

- 第二次 imagegen 调用只重生成地表，把草地约束为安静灰石绿底、极少草叶；石板改成少量大块；水纹改成低对比长线。两次提示词和两张原画均保留。
- 运行图集从同一建筑原画分别裁屋脊段、连续瓦面、净白墙，消除重复檐口；不是重画几何屋顶。
- 植被、山石、道具保留原画墨线，透明边界二值化，适度恢复缩小后的明暗差；使用邻近色降色且不抖动，避免人为增加散点。
- 用像素等式约束兼容边，拐角同时求解。草变体彼此上下左右相接；两水帧可互接；石板中路自平铺、左/中/右横接且左右边沿接草；屋顶、墙、栅栏按各自左/中/右规则拼接。独立树石道具四边透明，不把整棵树当作连续地表。
- 运行图集另按现有地图的全部地面邻接关系，以及建筑/木栏实际邻接关系，逐条校正和验证 RGBA 相等。不同材质与有端点的建筑模块不承诺任意乱接；允许的方向在 `seam_pairs.json` 中明确列出。

验收命令（仓库根目录，有 Python/Pillow、Node 和现有 TypeScript 依赖）：

```sh
PYTHONDONTWRITEBYTECODE=1 python3 scripts/build_aesthetic_tiles.py --revision 0
PYTHONDONTWRITEBYTECODE=1 python3 scripts/build_aesthetic_tiles.py --revision 1
PYTHONDONTWRITEBYTECODE=1 python3 scripts/verify_aesthetic_tiles.py
```

旧 `public/assets/mvp/_generate.py`、`_verify.py` 是之前 Kenney 33 帧、全局 16 色素材的历史工具，不能用于重建或验收这版地形；运行旧生成器会覆盖本次交付。当前以这里列出的两个脚本为准。旧 `docs/素材说明.md` 是历史说明，本次依权限未修改。

最终已实际打开 `contact_sheet.png` 与 `town_final.png` 复看：草地的斑驳密度、水面的强斜纹与建筑重复檐口较第一版明显降低，路边没有继承红白碎屑。16×16 下疏草和水纹仍很轻，石板内部仍能看出重复，这是保留的画面限制。机检通过 35 帧/1 补位、地表全不透明、独立物件透明留边、MVP 合法拼接和 3,330 处真实地图地面邻接，以及实际建筑/围栏拼接。全部 src 文件的前后 SHA-256 一致。

后处理与验证环境为 Python 3.12、Pillow 12.3.0，读取地图使用仓库现有 TypeScript 依赖。地形每帧先自适应降到 32 色，再校正边界；边界校正可能增加颜色数。本次不沿用旧版全图 16 色要求，manifest 的 `palette` 是实际地形 RGBA 色表，`legacyCompanionPalette` 保留其他历史素材的原色表。

## 来源、授权与生成提示词

新地形原画由本次内置 OpenAI imagegen 调用生成，非 Kenney 图块换色、非下载素材，也没有使用 CLI/API key。第一张使用用户给定《水泽》图片作为风格参考；参考原图没有复制进仓库，也不声明它的版权。新增生成内容不冒称第三方 CC0 素材，不在此替用户作额外授权承诺。

运行图集中未替换的 Kenney 部分沿用仓库已有来源与 CC0 说明，原始许可见 `public/assets/mvp/sources/`。人物、神兽、UI 没有在本任务中重生成或更改；旧来源说明不能用来描述本次 imagegen 地形。contact sheet 的字体只栅格化为验收标注，不分发字体文件。

完整提示词分别见 `aesthetic/prompt.txt` 和 `aesthetic/ground_prompt_v2.txt`。第一次要求工笔深墨线、石青石绿朱砂赭石、低饱和、正交地表、透明独立物件、六行六列；第二次针对自检问题要求极简草底、四块大石板、细而低对比的水平水纹，禁止点状路边、碎屑与密集颗粒。

## 尚未解决

- 16×16 是现有代码固定的图块尺寸，工笔细线与矿物色细节缩小后仍有明显损失，不能达到参考图的大幅插画密度。
- 现有地图仍以规则网格成排种树、建筑占固定矩形；本次只换素材，未重排地图，因此整排重复感仍存在。
- 芦苇、灯笼和新水帧已在图集中交付，但现有地图没有对应新增摆放或水面动画接线；本次没有改代码补上。
- 旧版人物、战斗神兽的像素阶梯、纯色战斗背景，以及字体、按钮和血条的风格冲突未处理；自评第 5 项仍存在。
- 边缘像素完全相等可以验证接缝，但不能消除小图块内部重复图案；最终预览用于人工复核其可接受程度。
